# 📱 Social Media App

A modern, full-featured social media platform designed to help users connect, share content, and interact with each other.

The platform provides features such as **friends, followers, posts, stories, profiles, likes, comments, notifications, and more**, creating a complete social networking experience.

## ✨ Features

### 👤 User Profiles

* Create and customize your profile
* Profile picture and cover image
* View user information
* View user's posts, followers, and following

### 👥 Friends & Followers

* Send and accept friend requests
* Remove friends
* Follow and unfollow users
* View followers and following lists

### 📝 Posts

* Create posts
* Edit and delete posts
* Share text and images
* Like and unlike posts
* Comment on posts
* View posts in a personalized feed

### 📸 Stories

* Create stories
* View stories from friends and followed users
* Stories automatically expire
* Support for images and other media

### 💬 Social Interactions

* Like posts
* Comment on posts
* Reply to comments
* Follow users
* Add friends
* Receive notifications for interactions

### 🔔 Notifications

* Friend requests
* New followers
* Likes
* Comments
* Other important account activity

### 🔐 Authentication

* User registration
* Login and logout
* Secure authentication
* Password management
* Account settings

### 🔍 Search

* Search for users
* Discover new people
* Find profiles and content

